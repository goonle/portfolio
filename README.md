## Tech Stack

- Next.js 15
- React
- TypeScript
- Tailwind CSS v4
- Framer Motion
- Lucide React
- shadcn/ui

## Features

- Responsive portfolio design
- Dark / Light mode
- Smooth scroll animations
- Animated skill bars
- Mobile navigation menu
- Reusable UI components

## What I Learned

### React Hooks

#### useState
Stores values and re-renders when the value changes.

#### useRef
Remembers values without re-rendering. Often used for DOM access.

#### useEffect
Runs side effects after rendering.

Examples:
- API calls
- LocalStorage
- Event listeners
- IntersectionObserver
- Animations

#### forwardRef
Allows parent components to pass refs into child components.
